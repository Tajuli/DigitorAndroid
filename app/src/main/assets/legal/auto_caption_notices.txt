ONNX Runtime
Artifact: com.microsoft.onnxruntime:onnxruntime-android:1.27.0
License: MIT License
Purpose: Native inference runtime shared by sherpa-onnx and Digitor's PP-Matting fallback.

Auto CC V86 does not package or use Whisper, WhisperKit, ggml, Qualcomm QNN, Omnilingual ASR, or the
former WhisperKit FFmpeg runtime. Recognition is performed locally with Zipformer. Fast mode uses
greedy decoding; Accurate mode adds speech normalization, silence-aware segmentation, incremental
streaming input and wider beam search. Bengali, English, Chinese, Korean and French are the first
international language packs. Auto detection remains limited to Bengali + English when both packs
are installed. User audio/video is not uploaded to a speech API.
