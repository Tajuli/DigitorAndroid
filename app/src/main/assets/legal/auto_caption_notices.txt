No English base pack is required. The language picker currently exposes Bengali, English, Hindi,
Arabic, Indonesian, Japanese, Russian, Thai, Vietnamese, Chinese, Korean and French. The six choices
backed by the multilingual model share one physical download. Urdu is not exposed yet because this
feature remains Zipformer-only and no compatible Urdu Zipformer pack is registered.

Models are downloaded only after explicit user action, cached in private app storage and not bundled
in the APK. User audio/video is not uploaded to a speech API.

ONNX Runtime
Artifact: com.microsoft.onnxruntime:onnxruntime-android:1.27.0
License: MIT License
Purpose: Native inference runtime shared by sherpa-onnx and Digitor's PP-Matting fallback.

Auto CC does not package or use Whisper, WhisperKit, ggml, Qualcomm QNN, Omnilingual ASR or Dolphin.
Recognition is local with Zipformer / Zipformer2 models. Transducer packs use greedy or modified-beam
decoding; Hindi uses the sherpa-onnx streaming Zipformer2-CTC path. Auto detection remains limited to
Bengali + English when both dedicated packs are installed.
