ONNX Runtime
sherpa-onnx uses ONNX Runtime internally. Digitor already includes Android ONNX Runtime for its
PP-Matting reliability fallback. ONNX Runtime is distributed under the MIT License; retain the
upstream ONNX Runtime notices/license with production distributions as applicable.

Auto CC V79 does not package or use Whisper, WhisperKit, ggml, Qualcomm QNN, or the former
WhisperKit FFmpeg runtime. Recognition is performed locally on the device. The selected speech model
is downloaded on first use and cached in private app storage; user audio/video is not uploaded to a
speech API.
